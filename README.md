# Экзаменационный проект PT-Start

## О проекте
Данный репозиторий содержит **уязвимое веб-приложение**, разработанное в рамках экзамена по курсу **PT-Start** (ДВФУ).

Проект демонстрирует полный цикл: создание уязвимого веб-приложения, работу с ним через **CURL**, эксплуатацию **SQL-инъекции** и защиту приложения с помощью **Web Application Firewall (WAF)**.

---

## Структура проекта

- **`html/`** — исходный код веб-приложения (PHP)
- **`screens/`** — скриншоты выполнения всех этапов экзамена (разбиты по папкам)
- **`docker-compose.yml`** — конфигурация для запуска приложения в Docker

---

## Выполненные требования

### 1. Уязвимое веб-приложение
- Страница регистрации пользователей
- Страница авторизации
- Реализация механизма Cookie
- Приватная страница приветствия (`Привет, имя_пользователя`)
- Приложение полностью обернуто в **Docker**

### 2. Работа с CURL
- Регистрация пользователя `Administrator` через браузер
- Регистрация пользователя в формате `Фамилия_ИО` **только через CURL**

### 3. Атака SQL Injection
- Успешная эксплуатация SQLi через форму авторизации
- Получена информация о:
    - Базе данных
    - Пользовательских таблицах
    - Всех пользователях и их паролях
- Выгружены данные пользователя `Administrator`

### 4. Защита WAF
- Приложение запущено за **WAF**
- Продемонстрирована блокировка SQL-инъекции
- Зафиксированы срабатывания правил WAF
